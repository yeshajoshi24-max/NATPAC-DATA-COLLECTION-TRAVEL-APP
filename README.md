🚦 NATPAC Data Collection Travel App
  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.
  
A data collection application developed for NATPAC to streamline and digitize travel survey processes. The app enables efficient recording of commuter behavior, trip details, and route information for transportation analysis.

🚀 Overview

This project focuses on simplifying traditional manual travel surveys by providing a digital platform for collecting structured and accurate transportation data. It is designed to assist researchers and planners in analyzing mobility patterns and improving urban transport systems.

✨ Features
📍 Capture trip details (origin, destination, time)
🧭 Route and travel mode tracking
📝 Survey-based data collection interface
📊 Structured data storage for analysis
📱 User-friendly and responsive UI
🔄 Real-time data entry and updates
🛠️ Tech Stack
Frontend: HTML, CSS, JavaScript
(Add: React / Flutter / etc. if used)
Tools: Figma / VS Code
🎯 Objectives
Digitize transportation data collection
Improve accuracy and reduce manual errors
Enable faster and scalable data analysis
Support research in urban mobility and planning
📌 Use Case

Designed for organizations like NATPAC to conduct travel behavior surveys and gather real-time commuter data efficiently.
